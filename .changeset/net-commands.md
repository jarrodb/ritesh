`riteshjs/net` (and `Rite.net` in the bundle): opt-in network commands that run in the visitor's browser. `ipcalc` (IPv4 and IPv6 address math, strict parsing), `dig` (DNS over HTTPS, the site's resolvers only), `ipv6` (the visitor's IPv4 and IPv6 reachability), and `httping` (HTTPS round trips to endpoints the site names). Output from the network is shown as text, escape sequences included.
