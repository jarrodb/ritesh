# Security

Report a vulnerability through GitHub's private vulnerability reporting: the repository's Security tab, "Report a vulnerability". Do not open a public issue.

In scope: the `ritesh` package (output filtering, the rite.1 client, link handling) and the `ritesh/server` Go module (authentication, sessions, path confinement, limits).

You get an acknowledgement within 7 days. Fixes ship as patch releases with an advisory.
